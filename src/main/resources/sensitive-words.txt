# 违禁词配置文件
# 适用范围：
# - AI 股票大师
# - AI 超级智能体
#
# 维护规则：
# 1. 每行一个词或短语。
# 2. 空行会被忽略。
# 3. # 开头的行会被当作注释忽略。
# 4. 英文大小写不敏感。
# 5. 会自动处理全角/半角差异和零宽字符。
# 6. 会额外进行紧凑匹配，用于拦截在词中插入空格、标点、符号的绕过写法。
# 7. 当前 Advisor 是“命中即拦截”，因此不要放过于宽泛的单字词，避免误伤正常提问。
# 8. 优先维护明确违规、明确高风险、业务不允许处理的词或短语。
#
# 建议维护方式：
# - 金融合规类：放项目明确不能承诺或不能协助的投资表达。
# - 隐私信息类：放用户不应提交的敏感身份或凭证信息。
# - 安全风险类：放明确违法、攻击、破坏、交易黑灰产相关词。
# - 内容安全类：放色情低俗、暴力极端、仇恨辱骂等不适合 AI 回复的内容。
# - 测试词请保留在测试环境；生产环境可删除“测试词”分区。
